# Линейная регрессия в Python: шпаргалка по statsmodels

Библиотека [`statsmodels`](https://www.statsmodels.org/) — одна из базовых для статистического и эконометрического анализа в Python. Эта шпаргалка — о линейной регрессии: спецификация, подгонка, проверка гипотез, прогноз и диагностика.

Что ещё есть в библиотеке ([руководство пользователя](https://www.statsmodels.org/stable/user-guide.html)):

- **регрессионные модели:** обобщённая линейная модель, регрессия с дискретной зависимой переменной (logit, probit и др.), робастная и квантильная регрессия, ANOVA;
- **временные ряды:** ARMA/ARIMA, экспоненциальное сглаживание, ARDL, VAR, VECM, модели пространства состояний, модели с переключением режимов, фильтрация, тесты единичного корня;
- **статистические инструменты:** проверка гипотез, эмпирическая функция распределения, графики, оформление результатов.

## Порядок работы с моделью

1. **Спецификация** — создаём модель: какая переменная зависимая, какие регрессоры, откуда данные.
2. **Подгонка** — метод `.fit()` оценивает модель и возвращает объект с результатами.
3. **Работа с результатами** — коэффициенты, стандартные ошибки, тесты, прогнозы, диагностика.

Обозначения в шпаргалке: `df` — датафрейм с данными, `y` — зависимая переменная, `x1`, `x2` — регрессоры, `mod` — модель до подгонки, `res` — результат подгонки.

## Импорт

| Команда | Что даёт |
|-|-|
| `import statsmodels.formula.api as smf` | регрессии, спецификация через формулу: `smf.ols(...)` |
| `import statsmodels.api as sm` | регрессии, спецификация через матрицы регрессионного дизайна: `sm.OLS(...)` |
| `from statsmodels.formula.api import ols` | то же, что `smf.ols`, но короче в записи: `ols(...)` |
| `import statsmodels.tsa.api as tsa` | модели временных рядов |
| `import statsmodels.graphics.api as smg` | графики для регрессионного анализа |

## Спецификация модели

Два способа: через формулу и через матрицы регрессионного дизайна `y`, `X`.

### Через формулу

```python
mod = smf.ols(formula='y ~ x1 + x2', data=df)
```

Формула — строка. Слева от `~` зависимая переменная, справа регрессоры через `+`.

| Формула | Модель |
|-|-|
| `y ~ x1 + x2` или `y ~ 1 + x1 + x2` | регрессия с константой |
| `y ~ 0 + x1 + x2` или `y ~ x1 + x2 - 1` | регрессия без константы |

Преобразования переменных записывают прямо в формуле:

| Преобразование | Запись |
|-|-|
| логарифм | `np.log(x)` (функция пакета `numpy`); годится и для зависимой переменной: `np.log(y) ~ x1` |
| квадрат регрессора | `I(x**2)` |
| умножить или разделить на число | `I(x*100)`, `I(x/60)` |
| произведение двух количественных регрессоров | `x1:x2` или `I(x1*x2)` |
| оба регрессора и их произведение | `x1*x2` — то же, что `x1 + x2 + x1:x2` |
| категориальная переменная | `C(x)` — набор бинарных переменных |
| категориальная переменная с выбором базовой категории | `C(x, Treatment(reference='название'))`; если категории — числа, без кавычек: `Treatment(reference=2)` |

**Важно**

- Арифметику внутри формулы нужно заключать в `I(...)`. Без этого знаки читаются по-другому:
  - `x**2` без `I()` — ошибки не будет, но в модель войдёт просто `x`, без квадрата;
  - `x1*x2` без `I()` — в модель войдут три регрессора: `x1`, `x2` и их произведение;
  - `x*100` и `x/60` без `I()` — ошибка `PatsyError`.
- Степень — это `**`, а не `^`: `I(x^2)` ошибки не даёт, но считает не квадрат.
- Чтобы писать `np.log(...)` в формуле, пакет должен быть подключён: `import numpy as np`.
- Логарифм нуля не определён: если у переменной есть нулевые значения, все коэффициенты получатся `NaN`.
- Если один из сомножителей в `x1:x2` — категориальная переменная, получится не одно произведение, а отдельный коэффициент при `x2` для каждой категории.
- Наблюдения с пропусками удаляются автоматически.
- Столбцы со строками превращаются в набор бинарных переменных автоматически, даже без `C(...)`. Одна категория — базовая — в модель не входит.
- Имена коэффициентов в результатах повторяют формулу, но с пробелами: `I(x1**2)` станет `I(x1 ** 2)`, категория — `C(x)[T.название]`.

### Через матрицы регрессионного дизайна

```python
y = df['y']                              # вектор зависимой переменной
X = sm.add_constant(df[['x1', 'x2']])    # матрица регрессоров со столбцом единиц
mod = sm.OLS(y, X, missing='drop')
```

**Важно**

- Константу нужно добавить самим: `sm.add_constant(X)` приписывает столбец единиц.
- Все преобразования переменных делаем вручную до создания модели.
- Параметр `missing` задаёт, что делать с пропусками: `'none'` (по умолчанию — ничего не проверять), `'drop'` (удалить наблюдения), `'raise'` (выдать ошибку).

Модель по формуле можно создать и так: `sm.OLS.from_formula(formula, data)`.

**О названиях.** В statsmodels зависимая переменная называется `endog`, регрессоры — `exog`. Это просто имена аргументов: к эндогенности и экзогенности регрессоров в эконометрическом смысле они отношения не имеют.

## Подгонка модели

```python
res = mod.fit()                                             # обычные стандартные ошибки
res = mod.fit(cov_type='HC3')                               # робастные к гетероскедастичности
res = mod.fit(cov_type='HAC', cov_kwds={'maxlags': 4})      # робастные к серийной корреляции
```

Параметр `cov_type` задаёт способ оценки ковариационной матрицы коэффициентов, то есть стандартные ошибки. Сами коэффициенты от него не зависят.

| `cov_type` | Стандартные ошибки |
|-|-|
| `'nonrobust'` | обычные (по умолчанию); верны при гомоскедастичной некоррелированной ошибке |
| `'HC0'` | робастные к гетероскедастичности, оценка Уайта |
| `'HC1'`, `'HC2'`, `'HC3'` | то же с поправками для малых выборок |
| `'HAC'` | робастные к гетероскедастичности и серийной корреляции (Ньюи–Уэст); обязательно указать число лагов: `cov_kwds={'maxlags': L}` |

Результат подгонки — объект класса [`RegressionResults`](https://www.statsmodels.org/stable/generated/statsmodels.regression.linear_model.RegressionResults.html).

## Результаты подгонки

### Протокол

```python
res.summary()                 # полный протокол
res.summary(slim=True)        # сокращённый
res.summary(alpha=0.10)       # доверительные интервалы с вероятностью 90 %
res.summary().tables[1]       # только таблица коэффициентов
```

Протокол можно получить в виде текста в разных форматах: `res.summary().as_text()`, `.as_latex()`, `.as_html()`, `.as_csv()`. Это методы протокола, а не результата; они возвращают строку, которую можно записать в файл.

Несколько моделей в одной таблице:

```python
from statsmodels.iolib.summary2 import summary_col
summary_col([res1, res2], stars=True, model_names=['(1)', '(2)'])
```

### Коэффициенты и их точность

| Атрибут | Описание |
|-|-|
| `res.params` | оценки коэффициентов |
| `res.params['x1']` | оценка коэффициента при регрессоре `x1` |
| `res.bse` | стандартные ошибки коэффициентов |
| `res.tvalues` | t-статистики для гипотез о равенстве коэффициентов нулю |
| `res.pvalues` | P-значения этих гипотез |
| `res.conf_int(alpha=0.05)` | доверительные интервалы |
| `res.cov_params()` | ковариационная матрица оценок |

Так же по имени берётся одно значение из `res.bse`, `res.tvalues` и `res.pvalues`: `res.tvalues['x1']`. Из таблицы доверительных интервалов строку берут через `.loc`: `res.conf_int().loc['x1']`.

Имя — как в `res.params`. Константа называется `'Intercept'` при спецификации через формулу и `'const'` после `sm.add_constant`; квадрат — `'I(x1 ** 2)'` с пробелами. Если модель задана массивами numpy, а не датафреймом, имён нет: значения берутся по номеру, `res.params[1]`.

### Качество подгонки

| Атрибут | Описание |
|-|-|
| `res.nobs` | число наблюдений $n$ |
| `res.df_model` | число регрессоров $k$ (без константы) |
| `res.df_resid` | число степеней свободы остатков, $n-k-1$ |
| `res.rsquared` | $R^2$ |
| `res.rsquared_adj` | скорректированный $R^2$ |
| `res.centered_tss` | TSS, общая сумма квадратов |
| `res.ess` | ESS, объяснённая сумма квадратов |
| `res.ssr` | RSS, сумма квадратов остатков |
| `res.scale` | $s^2$, оценка дисперсии ошибки; стандартная ошибка регрессии — `np.sqrt(res.scale)` |
| `res.aic`, `res.bic` | информационные критерии Акаике и Байеса |
| `res.fvalue`, `res.f_pvalue` | F-статистика и P-значение теста на значимость регрессии |

Осторожно с обозначениями: в statsmodels `ssr` — это сумма квадратов остатков (RSS), а `ess` — объяснённая сумма квадратов.

### Остатки и прогнозы

| Атрибут или метод | Описание |
|-|-|
| `res.resid` | остатки |
| `res.fittedvalues` | предсказанные значения для наблюдений выборки |
| `res.predict(new)` | точечный прогноз для новых данных |
| `res.get_prediction(new).summary_frame(alpha=0.05)` | прогноз с интервалами |

Новые данные — датафрейм со столбцами, названными как в формуле:

```python
new = pd.DataFrame({'x1': [12, 16], 'x2': [5, 10]})
```

В таблице `summary_frame` столбцы `mean_ci_lower` и `mean_ci_upper` — интервал для среднего значения, `obs_ci_lower` и `obs_ci_upper` — для отдельного наблюдения.

Если зависимая переменная в формуле — `np.log(y)`, прогнозируется логарифм; прогноз самой величины — `np.exp(...)` от него.

## Проверка гипотез

| Метод | Тест |
|-|-|
| `res.t_test(...)` | t-тест для одного линейного ограничения |
| `res.f_test(...)` | F-тест для нескольких линейных ограничений |
| `res.wald_test(...)` | тест Вальда для линейных ограничений; при обычных ошибках совпадает с F-тестом, при робастных выдаёт статистику $\chi^2$ |
| `res.compare_f_test(res_restricted)` | F-тест для сравнения вложенных моделей: модель с ограничениями против полной |

Гипотезу записывают строкой из имён коэффициентов — таких, как в `res.params`:

```python
res.t_test('x1 = 0.1')                     # коэффициент равен 0,1
res.t_test('x1 - x2 = 0')                  # два коэффициента равны
res.f_test('x1 = 0, I(x1 ** 2) = 0')       # два коэффициента равны нулю одновременно
```

Тесты используют ту ковариационную матрицу, с которой подогнана модель: после `fit(cov_type='HC3')` они робастные. Исключение — `compare_f_test`: он считается по суммам квадратов остатков и верен только при гомоскедастичной ошибке.

## Диагностика модели

Тесты лежат в модуле [`statsmodels.stats`](https://www.statsmodels.org/stable/stats.html).

```python
from statsmodels.stats.diagnostic import (het_breuschpagan, het_white,
                                          acorr_breusch_godfrey, linear_reset)
from statsmodels.stats.stattools import durbin_watson, jarque_bera
from statsmodels.stats.outliers_influence import variance_inflation_factor
```

| Что проверяем | Тест | Команда |
|-|-|-|
| гетероскедастичность | Бройша–Пагана | `het_breuschpagan(res.resid, res.model.exog)` |
| | Уайта | `het_white(res.resid, res.model.exog)` |
| | Голдфелда–Квандта | [`het_goldfeldquandt()`](https://www.statsmodels.org/stable/generated/statsmodels.stats.diagnostic.het_goldfeldquandt.html) |
| | ARCH-тест Энгла (условная гетероскедастичность) | [`het_arch()`](https://www.statsmodels.org/stable/generated/statsmodels.stats.diagnostic.het_arch.html) |
| серийная корреляция | Бройша–Годфри | `acorr_breusch_godfrey(res, nlags=2)` |
| | Дарбина–Уотсона (статистика) | `durbin_watson(res.resid)` |
| | Льюнга–Бокса | [`acorr_ljungbox()`](https://www.statsmodels.org/stable/generated/statsmodels.stats.diagnostic.acorr_ljungbox.html) |
| | LM-тест | [`acorr_lm()`](https://www.statsmodels.org/stable/generated/statsmodels.stats.diagnostic.acorr_lm.html) |
| функциональная форма | RESET-тест Рамсея | `linear_reset(res, power=3, test_type='fitted', use_f=True)` |
| нормальность ошибки | Харке–Бера | `jarque_bera(res.resid)` |
| мультиколлинеарность | VIF регрессора с номером `j` | `variance_inflation_factor(res.model.exog, j)` |
| влиятельные наблюдения | рычаги, расстояния Кука | `res.get_influence()` |

Для функций, приведённых ссылкой, аргументы смотрите в документации.

Замечания.

- `het_breuschpagan`, `het_white` и `acorr_breusch_godfrey` возвращают четыре числа: LM-статистику, её P-значение, F-статистику и её P-значение.
- `jarque_bera` возвращает статистику, P-значение, асимметрию и эксцесс.
- В `variance_inflation_factor` столбец с номером 0 — константа, её VIF не смотрим; регрессоры нумеруются с 1.
- У объекта `res.get_influence()` есть атрибуты `hat_matrix_diag` (рычаги), `resid_studentized_external` (стьюдентизированные остатки) и `cooks_distance[0]` (расстояния Кука).

Полный перечень диагностических тестов — на странице [`statsmodels.stats`](https://www.statsmodels.org/stable/stats.html).

## Свойства модели до подгонки

Для модели `mod`, заданной формулой:

| Атрибут | Описание |
|-|-|
| `mod.formula` | формула модели |
| `mod.endog_names` | имя зависимой переменной |
| `mod.exog_names` | имена регрессоров, включая константу |
| `mod.endog` | наблюдения зависимой переменной (массив numpy) |
| `mod.exog` | матрица регрессоров (массив numpy) |
| `mod.nobs` | число наблюдений |
| `mod.df_model` | $k$, число регрессоров |
| `mod.df_resid` | $n-k-1$ |
| `mod.rank` | ранг матрицы регрессоров; $k+1$, если нет чистой мультиколлинеарности |

Та же модель доступна после подгонки как `res.model`.
