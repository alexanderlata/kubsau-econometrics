# Модели уровень–уровень

## sleep equation \#1

Для набора данных `sleep75` рассмотрим регрессию **sleep на totwrk,
male**.

Объясняющие переменные: `totwrk` и `male`; контрольных нет.

Переменные: `sleep` — ночной сон, минут в неделю; `totwrk` — работа,
минут в неделю; `male` = 1 для мужчин.

Запишите спецификацию модели.

Оцените модель на данных и укажите коэффициенты подогнанной модели.
**Ответ округлите до 2-х десятичных знаков.**

Ответ:

| Переменная |  Оценка |
|:-----------|--------:|
| Intercept  | 3573.20 |
| totwrk     |   -0.17 |
| male       |   88.84 |

Модель была подогнана по 706 наблюдениям.

Интерпретируйте оценки коэффициентов при объясняющих переменных.

> [!TIP]
>
> ### Ответ
>
> - Уровень–уровень. При увеличении времени работы (`totwrk`) на 1
>   минуту в неделю при прочих равных время сна (`sleep`) в среднем
>   уменьшается на 0.17 минуты в неделю.
> - Бинарная переменная. У мужчин (`male` = 1) при прочих равных время
>   сна в среднем на 88.84 минуты в неделю больше, чем у женщин.

# Полулогарифмические модели

## sleep equation \#3

Для набора данных `sleep75` рассмотрим регрессию

`sleep ~ np.log(hrwage) + smsa + totwrk + male + marr + age + south + yngkid`

Объясняющие переменные: `np.log(hrwage)` и `smsa`; остальные —
контрольные.

Переменные: `hrwage` — почасовая зарплата.

Запишите спецификацию модели.

Оцените модель на данных и укажите коэффициенты подогнанной модели.
**Ответ округлите до 2-х десятичных знаков.**

Ответ:

| Переменная     |  Оценка |
|:---------------|--------:|
| Intercept      | 3440.19 |
| np.log(hrwage) |   -1.39 |
| smsa           |  -36.96 |
| totwrk         |   -0.16 |
| male           |   36.87 |
| marr           |   53.34 |
| age            |    2.37 |
| south          |   76.27 |
| yngkid         |   47.92 |

Модель была подогнана по 532 наблюдениям.

Интерпретируйте оценки коэффициентов при объясняющих переменных.

> [!TIP]
>
> ### Ответ
>
> - Уровень–лог. При увеличении почасовой зарплаты (`hrwage`) на 1% при
>   прочих равных время сна (`sleep`) в среднем уменьшается примерно на
>   0.014 минуты в неделю (оценка, делённая на 100).
> - Бинарная переменная. У жителей крупной городской агломерации (`smsa`
>   = 1) при прочих равных время сна в среднем на 36.96 минуты в неделю
>   меньше, чем у остальных.

В наборе данных 706 наблюдений, а модель подогнана по 532. Чем это
объясняется?

> [!TIP]
>
> ### Ответ
>
> У 174 человек значение `hrwage` пропущено: все они не входят в состав
> рабочей силы (`inlf` = 0). При подгонке statsmodels отбрасывает
> наблюдения с пропусками.
