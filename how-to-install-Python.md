# Инструкция по установке Python на свой компьютер

## Что мы будем делать и зачем?

Чтобы писать и запускать программы на Python, нам нужно установить несколько инструментов:

- **Miniconda** — программа, которая устанавливает Python и помогает управлять дополнительными библиотеками.
- **Библиотеки** — готовые «модули», которые мы будем подключать в своих программах: `pandas` для работы с таблицами, `matplotlib` и `seaborn` для графиков, `scipy` и `statsmodels` для статистики.
- **Jupyter Lab** — удобная среда для написания и запуска кода прямо в браузере. Именно в ней проходят семинары и выполняются домашние задания.

Установка займёт около 20–30 минут. Не спешите, делайте всё по шагам.

---

## Шаг 1. Установка Miniconda

> 📖 **Официальная документация:** если хотите сверяться с первоисточником, все способы установки описаны на сайте Anaconda:
> [anaconda.com/docs/getting-started/miniconda/install/overview](https://www.anaconda.com/docs/getting-started/miniconda/install/overview)

Есть два способа установить Miniconda — выберите тот, который вам удобнее.

### Способ А. Установка через графический установщик (проще для новичков)

1. Перейдите по ссылке: **[anaconda.com/docs/getting-started/miniconda/main](https://www.anaconda.com/docs/getting-started/miniconda/main)**
2. Скачайте установщик для вашей операционной системы:
   - **Windows** → файл с расширением `.exe`
   - **macOS** → файл с расширением `.pkg` (для компьютеров с процессором Apple выбирайте вариант с `arm64`, для старых Mac с процессором Intel — `x86_64`)
3. Запустите скачанный файл и следуйте инструкциям. **Все настройки оставляйте по умолчанию** — просто нажимайте «Далее» / «Next».

---

### Способ Б. Установка через командную строку / Терминал

Этот способ немного быстрее и не требует скачивать файл вручную.

#### Windows (PowerShell)

Откройте **PowerShell** (нажмите `Win+R`, введите `powershell`, нажмите Enter) и выполните команду:

```powershell
winget install -e --id Anaconda.Miniconda3
```

> ⚠️ Если команда `winget` не найдена, установите **App Installer** из Microsoft Store и попробуйте снова.

После установки **закройте PowerShell и откройте заново** — изменения вступят в силу.

---

#### macOS

Откройте **Терминал** (Launchpad → Другие → Терминал, или `Cmd+Пробел` → «Терминал») и выполните команды **по одной**:

**Шаг 1 — скачиваем установщик:**

```bash
curl -O https://repo.anaconda.com/miniconda/Miniconda3-latest-MacOSX-arm64.sh
```

> ⚠️ Если у вас Mac со старым процессором Intel (до 2020 года), замените `arm64` на `x86_64` в ссылке выше и в командах ниже.

**Шаг 2 — запускаем установщик:**

```bash
bash Miniconda3-latest-MacOSX-arm64.sh
```

**Шаг 3 — следуем инструкциям установщика:**
- Нажимаем `Enter` для прокрутки лицензионного соглашения, затем вводим `yes`.
- Путь установки оставляем по умолчанию — просто нажимаем `Enter`.
- На вопрос «Do you wish the installer to initialize Miniconda3?» вводим `yes`.

**Шаг 4 — закрываем Терминал и открываем заново**, чтобы изменения вступили в силу.

**Шаг 5 — удаляем скачанный файл (он больше не нужен):**

```bash
rm Miniconda3-latest-MacOSX-arm64.sh
```

---

#### Linux

Откройте Терминал и выполните команды по одной:

```bash
curl -O https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash Miniconda3-latest-Linux-x86_64.sh
```

Следуйте инструкциям установщика (аналогично macOS выше). После завершения закройте Терминал, откройте заново и удалите установщик:

```bash
rm Miniconda3-latest-Linux-x86_64.sh
```

---

## Шаг 2. Открываем командную строку

Не пугайтесь командной строки — нам понадобится всего несколько простых команд, и мы будем использовать их снова и снова.

- **Windows:** откройте меню «Пуск» → найдите папку *Miniconda3* → запустите **Anaconda Prompt (Miniconda3)**.
- **macOS / Linux:** откройте **Терминал** (на macOS: `Cmd+Пробел` → «Терминал»). Если он был открыт во время установки, закройте его и откройте заново.

Слева вы увидите надпись `(base)` — это значит, что Miniconda работает.

> ✅ **Проверка после установки:** введите команду `conda --version` и нажмите Enter.
> Если в ответ появилось что-то вроде `conda 25.x.x` — установка прошла успешно!

---

## Шаг 3. Обновляем пакеты

Сразу после установки обновим всё до актуальных версий. Введите команду и нажмите Enter:

```bash
conda update --all
```

> ⚠️ Обратите внимание: перед словом `all` стоят **два** дефиса (`--`), не один.

Программа попросит подтверждение — введите `y` и нажмите Enter. Подождите, пока обновление завершится (это может занять несколько минут).

---

## Шаг 4. Создаём рабочее окружение

В Python принято работать в **изолированных окружениях**. Думайте об окружении как об отдельной «папке» со своим набором библиотек — это позволяет не путать проекты между собой.

Мы создадим окружение с именем `courses`. **Это нужно сделать только один раз.** Введите команду:

```bash
conda create -n courses python=3.14
```

На вопрос `Proceed? [y/n]` введите `y` и нажмите Enter. Подождите завершения. Библиотеки установим на шаге 6.

---

## Шаг 5. Активируем окружение

Чтобы «войти» в созданное окружение, введите:

```bash
conda activate courses
```

> ✅ **Проверка:** Слева в командной строке вместо `(base)` должна появиться надпись `(courses)`. Если так — всё готово!

> ⚠️ **Важно:** Эту команду нужно вводить **каждый раз** при открытии командной строки перед началом работы.

---

## Шаг 6. Устанавливаем библиотеки

Убедитесь, что в командной строке слева написано `(courses)`, и выполните следующую команду — она установит всё необходимое для курса:

```bash
conda install -c conda-forge numpy pandas scipy statsmodels scikit-learn openpyxl matplotlib seaborn plotly jupyter jupyterlab ipykernel
```

Это займёт несколько минут. На вопрос `Proceed? [y/n]` снова ответьте `y`.

Затем установите пакет `wooldridge` — в нём лежат наборы данных из учебника Вулдриджа, с которыми мы работаем на лекциях и семинарах:

```bash
pip install wooldridge
```

---

## Шаг 7. Подключаем окружение к Jupyter

«Зарегистрируем» наше окружение в Jupyter, чтобы он видел все установленные библиотеки. Введите:

```bash
python -m ipykernel install --user --name=courses --display-name "Python (courses)"
```

---

## Шаг 8. Запускаем Jupyter и проверяем всё

В командной строке с активным окружением `(courses)` запустите Jupyter:

```bash
jupyter lab
```

В браузере автоматически откроется JupyterLab. Создайте новый ноутбук: нажмите **«+»** → выберите ядро **Python (courses)**.

> ✅ **Финальная проверка:** В ячейке ноутбука введите код ниже и нажмите `Shift+Enter`. Если напечатались версии библиотек, строка «Наблюдений в wage1: 526» и слова «Всё работает!» — установка прошла успешно!

```python
import numpy, pandas, matplotlib, seaborn, plotly, scipy, statsmodels
import wooldridge

for module in (numpy, pandas, matplotlib, seaborn, plotly, scipy, statsmodels):
    print(f"{module.__name__:12s} {module.__version__}")
print("Наблюдений в wage1:", len(wooldridge.data("wage1")))
print("Всё работает!")
```

Чтобы остановить Jupyter, вернитесь в командную строку и нажмите `Ctrl+C`.

## Возникли проблемы?

Вот самые частые ситуации:

| Проблема | Что сделать |
|---|---|
| Команда `conda` не найдена | Windows: откройте **Anaconda Prompt** из меню «Пуск», а не PowerShell. macOS / Linux: закройте Терминал и откройте заново |
| `conda create` пишет, что окружение `courses` уже существует | Создавать его заново не нужно: активируйте его (шаг 5) и выполните шаг 6 |
| `ModuleNotFoundError: No module named 'wooldridge'` | В окружении `(courses)` выполните `pip install wooldridge` (шаг 6) |
| Слева написано `(base)`, а не `(courses)` | Выполните `conda activate courses` |
| В Jupyter нет ядра «Python (courses)» | Повторите шаг 7 |
| `ModuleNotFoundError: No module named 'pandas'` | В ноутбуке выбрано не то ядро: меню **Kernel → Change Kernel → Python (courses)**. Если не помогло, закройте Jupyter и запустите заново после `conda activate courses` |
| Команда `jupyterlab` не найдена | Команда пишется через пробел: `jupyter lab` |
| В Jupyter не видно ноутбуков курса | Jupyter запущен не из папки курса: остановите его (`Ctrl+C`), перейдите в папку курса командой `cd` и запустите снова |
| PowerShell пишет, что выполнение сценариев отключено | Используйте **Anaconda Prompt** из меню «Пуск» вместо PowerShell |
| Установка обрывается с ошибкой `CondaHTTPError` | Проверьте интернет, отключите VPN и повторите команду |
| Ошибка при установке библиотеки | Напишите мне — разберёмся вместе |

Если что-то не получается, не паникуйте — приходите на консультацию или пишите в чат курса.

## Шпаргалка: команды на каждый день

```bash
conda activate courses            # активировать окружение (каждый раз!)
cd путь_к_папке_курса             # перейти в папку с материалами курса
jupyter lab                       # запустить JupyterLab
conda update --all                # обновить все библиотеки (раз в несколько месяцев)
```

> Jupyter показывает файлы той папки, из которой он запущен. Поэтому сначала переходите в папку курса командой `cd`, а затем запускайте `jupyter lab`.

## По желанию: работа в VS Code

Этот раздел необязателен. На семинарах мы работаем в JupyterLab, и шагов 1–8 для курса достаточно. Но те же ноутбуки можно открывать в редакторе **Visual Studio Code** — он использует то же окружение `courses`, поэтому сначала выполните шаги 1–7.

1. Скачайте и установите VS Code: [code.visualstudio.com](https://code.visualstudio.com). Настройки установщика оставляйте по умолчанию.
2. Откройте панель расширений (значок с четырьмя квадратами слева или `Ctrl+Shift+X`, на macOS — `Cmd+Shift+X`) и установите два расширения от Microsoft: **Python** и **Jupyter**.
3. Откройте папку курса: **Файл → Открыть папку** (**File → Open Folder**).
4. Откройте любой ноутбук — файл с расширением `.ipynb`. Справа вверху нажмите **Select Kernel** → **Python Environments** → выберите окружение **courses**.
5. Проверьте установку: создайте новый ноутбук (**Файл → Создать файл → Jupyter Notebook**), выберите то же ядро и выполните проверочный код из шага 8. Ячейка запускается клавишами `Shift+Enter`, как в JupyterLab.

Активировать окружение командой `conda activate courses` здесь не нужно: VS Code запоминает выбранное ядро для каждого ноутбука.

| Проблема | Что сделать |
|---|---|
| В списке ядер нет `courses` | Закройте VS Code и откройте заново. Если не помогло — повторите шаг 7 и выберите ядро **Python (courses)** в разделе **Jupyter Kernel** |
| `ModuleNotFoundError` при запуске ячейки | Выбрано не то ядро: нажмите на название ядра справа вверху и выберите **courses** |
| VS Code предлагает установить `ipykernel` | Выбрано окружение `base`, а не `courses`: смените ядро |
